# 家庭维修派工台

端口规划：`5114`

```bash
npm install
npm run dev
```

在家庭维修事项基础上扩展的预算派工工作台，数据保存在 localStorage，刷新后保留：

- 预置王师傅、李师傅、赵师傅三位师傅，本月预算额度 ¥800。
- 待处理事项可安排师傅与上门时段（日期 + 上午/下午）：同一师傅同一时段只能接一项；预计费用会占用额度。
- 时段冲突或剩余额度不足时整次拒绝，事项状态与排期均不改变。
- 处理中事项可登记实际费用完工：未超总额度直接完成并按实际费用结算；超额则进入「待确认」，仍按预计费用占用原额度，确认追加后才完成，也可撤销登记。
- 支持取消排期（释放额度占用）、按全部/待处理/处理中/待确认/已完成筛选，统计待处理、处理中、待确认数量及总额度、已支出、已占用、剩余可用。
- 旧版本地记录自动迁移：处理中事项即使没有师傅排期也按预计费用占用额度，已完成记录缺少实际费用时按预计费用计入支出。
