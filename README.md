# 家庭维修派工台

端口规划：`5114`

```bash
npm install
npm run dev
```

第二版：带预算额度的派工台。

- 预置三位师傅（水电 / 木工 / 家电）和本月 800 元额度，顶部实时显示已占用与剩余额度。
- 待处理事项可派工：选择师傅、日期和时段；同一师傅同一时段只能接一项，预计费用会占用额度。剩余额度不足或时段冲突时整次拒绝，事项和排期不变。
- 完工登记实际费用：未超额直接完成并按实际结算；超额进入「待确认」，继续占用原额度，确认追加后才完成并按实际费用占用。
- 旧数据自动迁移：没有派工和额度字段的事项按预计费用占用额度。
- 筛选、统计与 localStorage 同步，刷新后数据保留。
